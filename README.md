# Vaultor

A local-first knowledge workspace for linked notes and files, built with React, Tiptap, Spring Boot, and SQLite.

All project documentation lives in [docs/](docs/README.md). Start with the [living codebase guide](docs/CODEBASE.md) for architecture, UI/design, development, deployment, and maintenance.

AI agents: read [AGENTS.md](AGENTS.md) before making changes and update the guide as part of each change.

For installation and device updates, see [the platform guide](docs/desktop/INSTALLATION-AND-UPDATES.md). Implementation agents own release preparation through [the release process](docs/desktop/RELEASE-PROCESS.md).
