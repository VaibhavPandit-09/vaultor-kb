Published Windows x64 and macOS arm64 on 2026-11-08. Immutable release source: 4352b9c17929b7240d4ee44bfef03cd201709369 / v0.26.0. Full D1–D4/S history is merged into master (merge 765d88e, D4 qualification a315b65). Verified native macOS arm64 DMG and signed sidecar added via absent-platform publication.

## What's changed

- **Desktop navigation:** compact History, Back/Forward, shared commands and contextual right-click menus.
- **Resource organization:** multi-selection, bulk commands, safe internal dragging, editor resource links at the actual drop position, collection memberships and tags.
- **Adaptive sidebar:** stable navigation with contextual working region, compact Open Notes, direct lazy linked-folder exploration, scalable Tags and compact collection hierarchy.
- **Native integration:** identity-based clipboard, membership copy/paste and explicitly scoped moves, prepared managed-file copies for Explorer/default apps and drag-out, Activity taskbar progress/background notifications, keyboard conventions.
- **Quality and reliability:** responsive density, focus/menu handoff, reduced motion, Save/read acknowledgement and source-scoped conditional rename. Existing structured editor, undo, source authorization and recovery remain authoritative.

## Semantics and limitations

Collection paste adds membership without duplicating content; move removes only its explicit source membership. Linked resources remain externally owned; organization never relocates their files. OS actions use validated prepared copies without exposing internal storage paths. Resource clipboard yields to native text editing. Native operations require eligible resources/local capabilities; browser and linked/remote restrictions remain explicit. Optional Jump Lists and enhanced print/PDF remain deferred.

D1/D2/S Windows interaction scope accepted; D3/D4 engineering is distinct from user acceptance. Physical drag/Explorer/default-app behavior, menus, taskbar/notifications, themes/motion, Snap/DPI/monitors/tray and detailed installation/upgrade experience remain user-owned. Historical JOURNAL_OWNER_LOCK / NATIVE_HOST_CLOSED provenance remains unproven. Fresh actual packaged qualification is mandatory.
