# Vaultor 0.13.0 — spatial desktop UI

Source tag: v0.13.0. Mac arm64 verified and ready for publication; Windows remains blocked.

## Changes

Library, Collection detail, Collections, Recent and Pinned progressively compress the same title/search/actions while scrolling, with accent blending and reachable pagination. Short lists settle correctly. Notes reclaim reading space through a compact title and Organization disclosure. Panes retain editor identity while focus adds depth/dimming/transparency; OLED honors the opacity slider. Sidebar and Side/Floating previews preserve spatial continuity. Command stages stay anchored to their query; Settings and utility dialogs use compact geometry and owned focus/Escape. Theme switching reveals a complete palette from its control with a soft radial wave,1100ms Smooth/500ms Snappy, interruption and immediate reduced-motion fallback.

The user accepted the redesign stream and requested integration into master. This release contains that stream only. It does not integrate other active AI branches.

## Installation and update

Fully quit Vaultor, including tray hosting. Download the Mac DMG, open it and drag Vaultor.app into Applications, replacing the previous app without deleting its data. Mac replacement remains manual; the signed sidecar supports the existing backup-aware import flow. No paid Apple signing/notarization is claimed. Keep the original installer/data backup for recovery. Browser clients use the UI of their selected host.

## Compatibility and recovery
