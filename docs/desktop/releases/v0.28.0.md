# Vaultor Next 0.28.0 for Windows x64

**Release candidate. Publication is pending Windows installer qualification.**

This Windows release replaces the old Electron version with the new Tauri/Rust application. It performs a one-time reset of the old local Vaultor workspace and application settings. Existing Electron-managed notes and attachments are not migrated. External linked files and independently exported backups are not deleted. Future Vaultor Next updates preserve the new application's data.

After publication, quit Electron Vaultor through the tray menu and run the downloaded Vaultor Next installer. The per-user installer uses the default install path and creates a fresh workspace on first launch. Keep independent backups outside Electron's managed storage. After installing, open Vaultor Next and pair Android alpha.29 to the new host if you use hosting. The original host approval is tied to the previous host identity.

Future Windows Next updates use **Settings → Application and Storage → Check for updates**, followed by **Update and restart**. The installer and signed Next update manifest remain separate from the Electron feed. Update signatures verify the installer bytes using the pinned Next key. Windows Authenticode availability is recorded during final qualification.

See the [M26-C Windows qualification](../../plans/VAULTOR-NEXT-M26-C.md#windows-release-gate) for tested predecessor versions, storage boundaries, source provenance, remaining checks and publication status.
