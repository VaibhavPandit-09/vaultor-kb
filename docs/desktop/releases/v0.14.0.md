## Installation, compatibility and recovery

Installed Windows0.4.1+: open **Updates → Check for updates → Update and restart**. For a manual installation, fully quit Vaultor including tray hosting, run the EXE over the existing installation and retain app data. Offline import requires the EXE and its signed sidecar together. See [installation steps](https://github.com/VaibhavPandit-09/vaultor-kb/blob/master/docs/desktop/INSTALLATION-AND-UPDATES.md).

API/client protocol3 remains unchanged; updater envelope minimumProtocol1 remains unchanged. Review capability requires the R5 host/client implementation. Full workspace archives write version4 with portable reviews; readers accept1–4. Older archive3 hosts reject archive4, so do not downgrade workspace data or import an archive4 package into the previous Mac build. Private credentials/review validators are excluded from portable exports. Host installation interrupts connections; clients reconnect afterward. [Update recovery](https://github.com/VaibhavPandit-09/vaultor-kb/blob/master/docs/desktop/UPDATES.md) owns backups and schema recovery; never blindly replace a live database.
