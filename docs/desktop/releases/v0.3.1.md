# Vaultor 0.3.1 — Scalable mixed browsing

## Availability

Windows x64 only — published. Mac arm64 packaging/key access and native verification are pending; the precise same-tag handoff is in [MAC-HANDOFF.md](../MAC-HANDOFF.md). No Ubuntu, Mac Intel or Android package is provided.

## Changes

- Sidebar Pinned/Recent each show up to 12 mixed shortcuts, sorted alphabetically/globally by recency. Collapse/hide/cache controls remain.
- One searchable Type filter replaces stacked categories and permanent tabs. Sidebar type choices persist per device; All is the default.
- Library, Recent, collection contents and Pinned use one content-sized list with bounded 100-item pages and true filtered counts. Query, scope, drafts and bulk resource organization remain intact.
- Shared icons/labels cover sidebar rows, browsing, Ctrl+K, pickers, previews and inline links. Resource type remains visible alongside collections/tags; file formats remain file metadata. Unsupported types refuse opening without changing the note.
- Pins remain organizational shortcuts or resources, using the existing mixed endpoint with additive kind/appliedKind and metadata. Older hosts cannot silently broaden an explicitly filtered pin query.

## Update and compatibility

Download Vaultor-0.3.1-windows-x64.exe and its .exe.vaultor.json into one folder. Window menu → Updates → Import update → choose the sidecar → Ready → Install update. Complete the installer and reopen Vaultor. Preserve app data; Java/Docker are bundled/unnecessary for installation.

Protocol remains 1. No database/index/resource-model migration. Update the connected host to 0.3.1+ for sidebar type persistence and pin filtering; updating a Windows client alone does not update a Mac host. Browser UI follows its host build. New clients retain normal All-pin browsing on older compatible hosts; filtered pins require server acknowledgment.

Original Ed25519 sidecar identity is preserved. This personal installer has no paid Windows Authenticode certificate; normal OS approval may be needed. Mac signatures/notarization/install/update verification are not claimed.
