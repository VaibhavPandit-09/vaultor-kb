# Vaultor 0.25.1 — Linked Markdown hyperlinks (Windows only)

Windows x64 qualified on 2026-11-02; publication pending. The immutable v0.25.1 tag will identify the release source. No Mac or Android artifact is part of this patch.

## Fix and compatibility

Inline linked Markdown already produced link marks but lacked ordinary-anchor styling. Theme-aware underlines, hover feedback and keyboard focus now make them visible in light/dark/OLED themes without changing managed resource chips. Ctrl+click or focused Enter activates links through existing authorized native resolution. Explicit trusted target metadata lookup allows unopened files to navigate before graph indexing. HTTPS activation uses the existing native URL policy.

Read-only formatted previews support inline and reference-style links by click or focused Enter. Editable reference-style links remain protected source nodes; wikilinks/aliases remain unsupported literal text. No Markdown conversion, source-byte rewrite, graph rescan, Save/recovery, source-grant, protocol, portable archive or updater-envelope change is introduced.
