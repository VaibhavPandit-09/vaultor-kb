# Vaultor 0.24.1 — Windows menu and import reliability

Windows x64 qualified on2026-10-29; GitHub publication is pending. Source tag will be immutable v0.24.1. Mac arm64 build/acceptance access is unavailable; Mac remains0.21.0. Android is unchanged. This is a Windows-only release and must not replace complete-platform Latest0.21.0.

## Changes

- Activity reserves the complete native window-control footprint and compresses at narrow widths. Caption buttons stay reachable over dialogs; Connections, Workspaces and Settings use their existing owners and shared focus behavior.
- Import review checks current Library/Trash/removed items rather than treating retained history as proof that items still exist. Deleted collections with surviving notes are explained. Fully removed targets permit a normal fresh import. Interrupted imports restore their original choices and refuse known removed resume targets.
- Clear Import folder/files, Import another copy and Skip imported files actions replace technical prose and the single-radio approval gate. Skip hides creation settings it ignores. Current Vaultor edits and source files remain unchanged.
- Activity, transfers, organization, lifecycle, connections, recovery and settings use shorter action-specific wording and disclose technical details on demand. Completed warnings remain available. Owned draft discard requires a separate confirmation.

## Compatibility and limits

Protocol3 and existing archive schemas are unchanged. Current import inventory requires additive host capability importPresence:1; update a remote host to0.24.1 to enable that check. Older/unreachable hosts show an explicit unverified state and offer deliberate new copies. Metadata lookup is bounded to200 IDs of each kind per request and6,000 unique item/collection IDs of each kind per review; it reads no document content and emits no change event. Import history stays device-local and nonportable. Recognition proves matching bytes/relative paths, not physical-folder ownership. Clearing local storage removes recognition. Changed-file in-place updates and organization-only reconstruction remain unsupported. No source originals are deleted or modified.

## Installation and update

Once published, installed Windows0.4.1+: Updates → Check for updates → Update and restart. For manual update, fully quit Vaultor including tray hosting, run the EXE and retain app data. Keep its original-key .vaultor.json beside the EXE for offline import. Personal EXEs are not Authenticode-signed; normal SmartScreen prompts may remain.
