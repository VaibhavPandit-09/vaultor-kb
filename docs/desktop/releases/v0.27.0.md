## What's changed

- Read practical instructions inside Vaultor: 15 bundled Help articles and a 42-feature catalogue.
- Search features, workflows, screen names, keywords, article text and current keyboard bindings locally, without GitHub or a network service.
- Browse by area/task, follow headings and related topics, use Help Back, copy instructions and inspect a live shortcut reference.
- Open Help from the application menu, command palette, Settings, Activity or the contextual sidebar action. Existing note editors and drafts remain in place.
- Future development and release publication must reconcile both user Help and engineering documentation against the exact platform source delta.

## Platform and safety boundaries

Help is read-only application content, separate from user resources, autosave, recovery, Library search, collections, Trash and workspace archives. Markdown has no raw HTML/scripts, embedded image fetching, filesystem navigation or privileged IPC. External HTTP(S) links use existing browser/Electron policy. Source Markdown/catalogue and content hashes ship with the UI; builds, desktop copying and release packaging reject stale/missing Help assets.

Windows 0.27.0 introduces Help. Mac 0.26.0 and Android alpha.28 do not have in-app Help. The Mac implementation remains unqualified source, explicitly marked development in the catalogue. A future Mac publication requires native qualification and accurate Help metadata; changes to this immutable source require a new version. Existing large-Markdown performance limits and user-owned D3/D4/physical-platform acceptance remain unchanged.
