# Vaultor 0.25.0 — Consistency & Refinement (Windows only)

Windows x64 release preparation on 2026-11-02. Source tag: v0.25.0 (immutable release source once qualification completes). Installer verification, minimal packaged startup and publication are pending. No Mac or Android artifact is part of this release.

## Changes

- Linked Markdown gains an owner-local relationship/backlink projection without rewriting external source. Shared path matching handles relative/encoded paths and unambiguous conventions. Queries stay inside their source grant; refresh reuses read-only batch presence instead of repeatedly registering known references.
- One Import interface supports file/folder browsing, multiple files and native drops through the existing review and Activity safeguards. Link folder retains separate external ownership.
- Shared button feedback, anchored menus, plus/minus sidebar disclosure, contextual ellipsis, compact menu bounds and focus restoration refine the existing desktop interface.
- Current documentation and eight stale test assertions are reconciled. No new dependencies, database/archive migration or Android changes.

Existing Mac0.24.2 and Androidalpha.28/code32 downloads remain unchanged. GitHub Latest remains0.21.0; this partial release is non-latest. Windows updaters discover stable platform pairs independently of Latest.

## Compatibility, limits and recovery

API/minimum-client protocol3/3, updater envelope1 and portable archive formats remain unchanged. Derived linked edges/bodies are local and excluded from portable exports; the backend keeps metadata-only linked descriptors. External files remain authoritative, and byte-exact explicit Save/protected recovery retain their native checks.

Wikilinks/aliases remain unsupported literals. External renames/moves/replacements conservatively create new identities. Indexed relationships are eventual and may be partial: Markdown up to1MiB, 10,000 admitted files, 16MiB shared derived cache, two200-entry directory pages/four files per tick; search text remains capped256KiB per file. Graph queries do not rescan folders. Physical filesystem/power-loss guarantees and universal1MiB typing performance are not newly certified.

Installed Windows0.4.1+: **Updates → Check for updates → Update and restart**. Manual users fully quit Vaultor including tray hosting and preserve app data; retain installer/sidecar together for offline import. [Installation](../INSTALLATION-AND-UPDATES.md) and [recovery](../UPDATES.md) own exact procedures.
