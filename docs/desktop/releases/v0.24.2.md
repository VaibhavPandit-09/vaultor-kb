# Vaultor 0.24.2 — Browse-header compression

Published Windows x64 and Mac arm64 on 2026-10-29 at [v0.24.2](https://github.com/VaibhavPandit-09/vaultor-kb/releases/tag/v0.24.2). Immutable source: `ae0a674a0924d11cde84190865f1bab1189af909`; subsequent publication-ledger commits are documentation only. Android is unchanged. Releases since 0.23.0 retain their disclosed large-document performance limits; complete-platform Latest remains 0.21.0 while updaters discover their matching stable platform pair independently.

## Changes

Search, type/presentation filters and page arrows remain available as Library, Recent, Pinned, Collections and collection-content headers compress. The same mounted controls move into the top working region with the existing reversible animation. Wide containers use one compact row; containers 940px and below use two rows to keep search editable. Secondary result/selection details use disclosure; search and filtering no longer disappear behind it. Focus, caret, current query/page, pointer/menu holds, scroll compensation and reduced-motion endpoints retain their owners.

Installed Windows 0.4.1+: Updates → Check for updates → Update and restart. For manual Windows update fully quit Vaultor including tray hosting, run the EXE and retain app data. For Mac, open the DMG and drag `Vaultor.app` to Applications to replace the existing version while preserving application data. Keep the original-key signed sidecar beside the installer for offline import. Personal EXEs are not Authenticode-signed and macOS DMG packages use personal ad-hoc codesigning with standard user Gatekeeper consent.
