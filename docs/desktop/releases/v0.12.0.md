# Vaultor0.12.0 — R5 review evidence and inbox

Status: implementation and installed-directory checks passed; final Windows installer/source tag/publication pending. Windows x64 only until exact-tag native Mac verification is completed. Development branch **ai/codex-current**, preserving R4 and incorporating only the user-requested master design-contract update. No ai/gemini-ui integration.

## Capability and use

R5 adds separate workspace-scoped review evidence and conditional open/resolved/dismissed triage. Sidebar **Review inbox**, note-header pending counts and file-preview entry open one shared focused surface. Filter/status counts, bounded pages, expandable original evidence, retained rows on refresh failure and local conflict feedback preserve context. Original note JSON/revisions are not changed by review/status actions. Missing/trashed targets retain evidence; changed quotes are clearly identified.

This is the **host/desktop/browser triage sprint**. Android alpha.11 remains unchanged/compatible for reading; Android capture and offline synchronization are R6 and are not enabled by installing this release. No new Android APK. Hosts/clients need0.12.0 for review capability/display; API/minimum client protocol3 remains unchanged.

Full workspace exports now use archive4 with portable reviews. Imports1–3 remain supported; archive4 is rejected by older hosts. Merge remaps review/target references; independent copies retain IDs inside their isolated namespace, with fresh private validators/workspace identity. Original provenance/status/quote survives. Import previews show review counts and replacement names review removal. Scoped note ZIP packages include reviews.json; standalone MD/PDF/Word presentation remains unchanged. [REVIEWS.md](../../workspace/REVIEWS.md) owns domain/API/portability and integration contracts.

## Platform and installation

Available after publication: original-key-verified Windows installer Vaultor-0.12.0-windows-x64.exe and its .vaultor.json sidecar. These are personal update signatures, not paid Windows Authenticode. No paid services/key replacement/CI secrets are introduced.

Installed Windows0.4.1+: open **Updates → Check for updates → Update and restart**. The app downloads and verifies the pair, protects work and runs the installer; manual download of two files is unnecessary. For a manual install, fully quit Vaultor (including tray hosting) and run the EXE without uninstalling/clearing data. Mac remains on its last verified build until the [exact v0.12.0 handoff](../MAC-HANDOFF.md) is performed; do not claim a Windows installer updates Mac. Browser users update their selected host.
