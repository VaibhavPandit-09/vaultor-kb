# Vaultor 0.7.1 — reliable scale and compact workspaces

**Windows x64 and macOS Apple Silicon (arm64).** No Linux/Android package is claimed.

- Large imports keep live operation status available during the atomic commit, avoiding the shared SQLite connection timeout. Historical status remains durable; maintenance reads are retryable. Authentication, save barriers and archive semantics are unchanged.
- Reference pages retrieve occurrences in one bounded batch rather than repeating whole traversal for every row. Totals/order/20 occurrences per row remain correct.
- Narrow workspaces show one focused pane with an explicit Pane selector, retaining all editors/documents/undo. Menu opens the responsive sidebar; Escape restores focus. Wider layouts restore panes without changing stored preferences. Native controls have reserved space.
- Desktop read-only connection checks wait briefly for approved startup maintenance. They never retry mutations or bypass approval/compatibility errors.

API/minimum client **3**, archive **3**, updater **1** remain unchanged; no schema/dependency migration. Update the host first for server fixes. A Windows update cannot upgrade a remote Mac host.
