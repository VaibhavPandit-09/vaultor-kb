## Installation and recovery

Installed Windows users: Updates → Update and restart. Alternatively fully quit Vaultor (including tray hosting), download the EXE and matching sidecar, install and reopen; retain app data. Hosting stops briefly and paired clients reconnect. Source files are never imported/moved by carrier setup. On drive loss, reconnect the same verified volume; protected primary drafts remain in Linked sources → Recovery. Interrupted source-volume artifacts require that volume to return before export/explicit restoration. No automatic Save replay or unresolved-evidence expiry.

Each carrier/primary store refuses allocations at100 operations/256MiB; acknowledged history is bounded to20 versions/64MiB per carrier. Review/export and explicitly remove copies to free space. Optional audit SACL parity, cloud placeholders, reparse/special files and existing hardlinks remain outside the ordinary-file write contract. API/min-client3/3, workspace/Markdown/reference schemas and signing identity remain unchanged.
