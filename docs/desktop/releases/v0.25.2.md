# Vaultor 0.25.2 — Single-click Markdown links (Windows only)

Windows x64 release candidate on 2026-11-02; package qualification and publication pending.

Linked Markdown inline links now open with an ordinary single click. The shared handler retains focused Enter, Ctrl/Command compatibility and Shift-to-new-pane navigation. Existing URL validation, native source resolution and filesystem confinement remain authoritative. Source serialization, byte-exact unchanged Markdown, Save/recovery and relationship indexing are untouched. Reference-style editable source nodes and unsupported wikilinks retain their existing behavior.

- Focused frontend26/26 pass: mounted link activation/marks, relative/nested/encoded fragments, HTTPS, ordinary text clicks, keyboard/repeat handling, Shift/Ctrl, unchanged source, explicit Save and Undo. Lint passes.
- Fresh TypeScript/production UI/server build, original-key package/payload verification and minimal packaged Windows acceptance pending.
