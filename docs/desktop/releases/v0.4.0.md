# Vaultor 0.4.0 — settings, managed images and expressive motion

Source tag: v0.4.0 (immutable release source; hash recorded in publication status).

## Changes

- Flat searchable Settings with Appearance, Workspace, Layout & previews and Keyboard; OLED black canvas, direct controls, scoped reset confirmations and local retry.
- Paste/drop screenshots or insert PNG/JPEG/WebP/GIF images as managed File resources. Original bytes retained; width/alignment, captions/alternative text, replacement, previews, native copying and original downloads. Shared editing, saved search, backlinks, archives and exports understand image placements.
- Smooth adds coordinated entrances/exits, moving selection indicators, sidebar disclosure, bounded row reveals and 2 px action hover feedback. Snappy stays quick; OS reduced motion removes movement. The explicit settings comparison runs only when requested. Typing, saves and refreshes do not replay page/list reveals.
- Dialog closure restores the captured source pane without waiting for its inert visual exit; no global-editor focus selection.

## Platform availability

Windows x64 installer and signed sidecar are built and verified; GitHub publication follows the source/tag gate. Mac arm64 access/original signing key/native verification remains unavailable in this Windows session. Windows-first release; Mac uses exactly v0.4.0 after the [Mac handoff](https://github.com/VaibhavPandit-09/vaultor-kb/blob/master/docs/desktop/MAC-HANDOFF.md). No Linux, Mac Intel or Android native package.

## Installation and update

Download **Vaultor-0.4.0-windows-x64.exe** and **Vaultor-0.4.0-windows-x64.exe.vaultor.json** into the same folder. Open window menu → Updates → Import update, select the sidecar, wait for Ready, then Install update. Complete the installer and reopen. Local-host installation interrupts connected devices; reconnect afterwards. Keep app data. Ed25519 update identity remains unchanged; this is a personal installer without paid Authenticode/notarization.

**Update both host and clients to 0.4.0.** API protocol/current minimum client is 2; old clients are refused before editing image documents. Update the host first, then its clients; do not edit with mismatched versions. A Windows client update does not update your Mac host. Updater-sidecar `minimumProtocol: 1` is the separate updater envelope protocol and intentionally lets existing 0.3.x apps import this signed update. No database or archive migration.

## Validation and limitations

Production frontend and fresh Java/server compilation, scoped ESLint and focused settings/image/motion/shared-document tests passed. Fifty-one focused frontend cases across nine files and eight Node updater/artifact cases passed in Sprint 3, alongside the previously recorded Sprint 1 and Sprint 2 checks (including twelve backend image/export/search/protocol cases). Final disposable packaged Windows integration passed settings OLED/Light/Dark and persisted accent, real OS image paste/original bytes/native copy, placement tools and saved-session reload, Smooth/Snappy timing and actual 2 px hover, moving selections, immediate Escape/source focus, Tab/Enter palette actions, retained editor/no typing animation, sidebar inert disclosure, narrow OLED and emulated reduced motion. Fourteen frames captured; representative themes/settings/palette/images inspected. All five UI files match fresh dist and embedded browser JAR bytes. Original-key preflight passed. Existing build warnings remain (Browserslist age, chunk size, mixed import, Java deprecation and ASAR disabled). No broad API smoke, Docker rebuild or user installation/uninstall. Native Mac, real two-device LAN, browser clipboard permission prompts, pointer/touch resizing and physical OLED hardware remain unverified. Pending image upload bytes remain in memory with exit warnings; successful originals remain normal resources if insertion cannot complete. Animated image exports render a static first frame with relevant warnings.

GitHub releases use manual pair download → in-app import/install. No automatic GitHub polling/feed or silent installation is claimed. See [update recovery](https://github.com/VaibhavPandit-09/vaultor-kb/blob/master/docs/desktop/UPDATES.md).
