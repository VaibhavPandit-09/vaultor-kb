# Vaultor 0.4.1 — one-click Windows updates

## Changes

Updates automatically discovers stable published GitHub releases for this device, downloads the signed manifest/installer internally and offers **Update and restart** on an installed Windows app. The action verifies bytes, saves work, stops local hosting, verifies its recovery backup, installs silently in the existing location and reopens Vaultor. Progress, cancellation, local retry and visible helper failures are retained. Manual import/custom source/repair/recovery move to Advanced. Original signing identity remains unchanged.

Windows x64 installer and original-key signed sidecar are verified. This is a Windows-only release; Mac automatic app replacement/package/native access remains unavailable. Mac and portable/development installs fetch verified packages but explicitly retain the manual installer handoff. No paid certificate/notarization/feed, new dependency, API protocol or database migration. API remains 2.

## Transition and future updates

From 0.4.0 or older, download the Windows EXE, save and Quit Vaultor via tray/menu, run the installer and reopen. This is the one transition manual installer update; direct installation skips the existing app's pre-update backup. Alternatively download the signed sidecar beside it and use the old Import update flow once for verified staging/backup. Afterwards: window menu → Updates → **Update and restart**. Hosts and clients update separately.

OS security prompts remain possible with this personal unsigned installer. No protections are disabled. Mac still requires native replacement verification; the exact handoff is in MAC-HANDOFF.md. No Linux/Mac Intel/Android native package.
