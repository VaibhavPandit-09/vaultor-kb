# Vaultor 0.3.0 — Coherent browsing

## Availability

**Windows x64 only.** Download Vaultor-0.3.0-windows-x64.exe and Vaultor-0.3.0-windows-x64.exe.vaultor.json together. Mac arm64 artifacts are not available yet: matching private signing-key access and native verification on the Mac mini remain outstanding. A verified Mac pair may be added later from the same immutable v0.3.0 source tag. No Ubuntu, Mac Intel or Android package is provided.

## Changes

- Library, Recent, Collections and Pinned share compact headings, grouped rows and content-sized borders. Sparse/empty pages no longer show oversized result boxes.
- Notes/Files groups have accurate independent counts, 12-item previews and View all; single-type pages stay bounded at 100. Pinned also groups Collections and uses alphabetical title search.
- Sidebar Pinned shows four per type; Recent shows six. Collapse or hide Pinned, Recent and Tags through Sidebar options → Customize sidebar; Restore defaults is available. Preferences persist per device and hidden sections stop browsing requests without clearing filters or cached rows.
- New note has an adjacent New collection dropdown; Import files uses a matching secondary button. Secondary row organization actions stay keyboard/touch accessible.
- Local failures retain usable rows and retry controls. Title-first search, content opt-in, scoped collections, mounted editors and pending drafts remain supported.

## Update

Download both Windows files into one folder. Open window menu → Updates → Import update, select the .vaultor.json, wait for Ready, then Install update. Complete the installer and reopen Vaultor. Keep existing app data; no Java or Docker installation is required. See [installation/update instructions](https://github.com/VaibhavPandit-09/vaultor-kb/blob/v0.3.0/docs/desktop/INSTALLATION-AND-UPDATES.md).

Protocol remains 1; no database/index migration or new endpoint is required. **Update the host to 0.3.0 to persist sidebar presentation settings.** An older host may drop the new local fields. A Windows client update does not update a Mac host; browser UI comes from its host. Device presentation is not included in portable workspace archives.

The installer is a free personal OS build, without paid Authenticode/notarization; its update sidecar is signed by Vaultor's original Ed25519 identity. Normal OS approval may still be needed. GitHub delivery uses download/import; ordinary GitHub asset URLs are not a supported automatic feed.
