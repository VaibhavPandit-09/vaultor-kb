# Vaultor 0.3.2 — OLED

## Availability

Windows x64 published 2026-10-07T18:09:05Z. [GitHub release](https://github.com/VaibhavPandit-09/vaultor-kb/releases/tag/v0.3.2). Both uploaded asset sizes/digests match local verified bytes. Mac arm64 packaging/key access/native verification remain pending. No Ubuntu, Mac Intel or Android package. See [Mac handoff](../MAC-HANDOFF.md).

## Changes

Separate OLED theme alongside OS/Light/Dark; OS remains default. Workspace, sidebar, notes, results and journey bar use true black. Neutral near-black raised surfaces, soft text, visible focus/selection and existing accent colors preserve hierarchy. Editor menus/code/table/preview surroundings use shared tokens. Media/PDF/export colors remain original. OLED overrides opacity without changing the saved transparency value; switching away restores it.

## Update

Download Vaultor-0.3.2-windows-x64.exe and .exe.vaultor.json into one folder. Window menu → Updates → Import update → select sidecar → Ready → Install update. Complete the installer and reopen. Settings → Local → Appearance → Theme → OLED. Update the connected host to 0.3.2+ for reliable persistence; updating a Windows client alone does not update a Mac host. Protocol remains 1; no database/index/archive migration. Original Ed25519 trust is retained; no paid Windows Authenticode/notarization is claimed.
