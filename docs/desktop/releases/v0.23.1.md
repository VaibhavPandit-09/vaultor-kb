## Changes

- Faster large-document opening and typing, with less redundant foreground layout work and native Save framing/retention work.
- Preserve original table/list source when independent draft checkpoints skip intermediate Undo states, including mixed code/table/list documents. Complete independent validation, revision checks, protected drafts and durable Save acknowledgements remain mandatory.
- Extend the existing developer benchmark with structural workloads and safe failure diagnostics; editor readiness no longer depends on a focus-only testing bridge.
