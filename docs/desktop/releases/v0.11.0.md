# Vaultor 0.11.0 — companion checkpoint service (R3)

Windows-only x64 host release; build and native gates passed, GitHub publication is the final gate. Native Apple Silicon verification is unavailable from this Windows workspace; Mac0.11.0 artifacts are not ready. Android alpha.10 is unchanged; offline downloads arrive in R4. API/minimum client3/3 and archive3 remain compatible; no database migration.

## Change

Hosts can prepare coherent read-only checkpoints for a workspace, selected collections or resources with explicit dependencies/file policy. Paged metadata, saved note JSON, original files and organization have fixed identities, hashes, expiry and availability coverage. Clients can estimate, cancel, resume single byte ranges and compare checkpoints without mixing live revisions or replaying edits. Replacement/revocation refuses delivery; originals, recovery and future review/import queues are untouched. This service is not a portable workspace ZIP or Android offline store.

Frontend/native-server compilation passed.
