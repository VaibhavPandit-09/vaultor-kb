## What changes

Windows This computer adds Linked sources → Link folder, native folder consent, paged hierarchy and Markdown rich-text editing with explicit Save/Ctrl+S to the original. Open Notes/panes/journeys, metadata-only collection/tag/pin references, private saved-content search, relative Markdown links and scoped raster/PDF previews are integrated. External clean changes refresh; dirty changes retain drafts and offer compact comparison, export, reload and reviewed disjoint combination. Recovery retains B/L/V plus captured/displaced objects across interrupted publication/restart/workspace loss.

[Linked-source guide](../../workspace/LINKED-SOURCES.md) is the authoritative user/safety contract; [implementation tracker](../../development/LINKED-SOURCES.md) records experiments and failed approaches. Existing managed notes, collections, updater signer and companion protocol3 remain intact. Archives containing external references use9/10 and never include external bodies, absolute root registrations or native grants.

## Supported envelope and limitations

- Windows x64, fixed local NTFS, ordinary user-owned files on the same volume as private recovery (normally C:). Other local NTFS volumes are read-only. No administrator helper.
- Rich text up to256KiB plus documented shape/input limits. UTF8/BOM/LF/CRLF and untouched source preserved. Unsupported syntax uses protected targeted editing; unsafe transforms retain drafts, never whole-document regeneration. Large/unqualified documents remain intact read-only.
- Existing multi-hardlink, ADS/EA, explicit integrity, encrypted/compressed/sparse/cloud/reparse/read-only files refuse direct writes. Ordinary owner/group/DACL/inheritance/creation/attributes are verified; physical identity and modification time change. Exact optional audit SACL parity is not promised.
- Detached capture/exclusive new-object publication avoids modifying aliases of the original. It has a missing-path window; explicit guarded restoration/metadata completion is available. Independent writers can still change files after checks; conflicts/uncertain receipts retain evidence. This is not atomic hash CAS or power-loss certification.
- External rename/move/atomic replacement conservatively creates a new navigation identity. Old sessions/references remain unavailable with drafts retained; explicit reauthorization is required. No automatic migration of collection references across external renames.
- Reviewed combination admits strictly separated single line hunks only; overlaps/adjacency/ambiguous provenance require export/reload/reapply. Undo survives cached remount, resets after eviction/restart.
- Search and assets are bounded as documented. No Mac/network/non-NTFS writes or cross-device linked-folder synchronization. Physical IME, hours-long all-pane sessions, independent security certification and physical power-loss testing remain unqualified.

## Update and recovery

Installed Windows0.4.1+ uses Updates → Update and restart; manual users retain EXE plus signed sidecar and fully quit tray hosting first. Back up external repositories separately: ordinary workspace/updater backups do not own or roll back linked files. Do not downgrade newer archives/databases into an older host. Disconnect removes grants, not original files. Export unresolved private recovery versions before explicitly removing them.
