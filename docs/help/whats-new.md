# What's New

## Desktop 0.26.0 — Windows x64 and Mac Apple Silicon

Published 2026-11-08. [Resource selection and dragging](interactions.md) brings page-scoped bulk actions, context menus, resource-link drops and safe membership clipboard operations. [Navigation](navigation.md) includes compact history and an adaptive sidebar with Open Notes, linked-folder exploration and scalable tags. [Desktop tools](desktop.md) covers prepared filesystem copies and Activity taskbar/background notification integration.

Collection paste adds membership without duplicate content. Linked resources retain external ownership. Subjective Windows D3/D4 acceptance remains pending; the release record distinguishes automated native evidence from user acceptance.

## Windows 0.25.0–0.25.2

Unified import acquisition, linked Markdown relationship discovery and single-click supported Markdown link activation shipped on Windows in this sequence. Mac received the consolidated capabilities with 0.26.0; do not infer them for an older Mac 0.24.2 installation. [Linked sources](linked-sources.md), [Import](transfers.md).

## Desktop 0.24.2

Browse search/filter/paging controls stay accessible through header compression. Mac's older published 0.24.2 baseline preceded its 0.26.0 release.

## Development after 0.26.0

This branch adds offline searchable Help, a feature catalogue and mandatory documentation reconciliation. These additions are **unreleased**, not a new 0.26.0 installer. Android is unchanged at alpha.28. [Platform support](platforms.md).

The existing engineering release ledgers remain the evidence source; this article summarizes user-visible changes and does not establish an independent release history. [Official release notes](https://github.com/VaibhavPandit-09/vaultor-kb/releases/tag/v0.26.0).
