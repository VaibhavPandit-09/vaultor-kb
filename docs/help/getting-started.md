# Getting started

Vaultor keeps notes, original files and references to linked Markdown together in a workspace. Collections organize resources without turning them into filesystem folders. Start in **Library**; use the sidebar to reach Collections, Pinned, Recent, Tags, Linked sources and Trash.

## Your first workflow

1. Choose **New note**, give it a title and type. Managed notes save automatically; watch the save status before closing or switching connections.
2. Type `/` for blocks or `[[` to link another resource. See [Notes and links](notes.md).
3. Use the resource Actions menu to add the note to a collection, apply tags or pin it.
4. Use **Search workspace** to find it again. Search starts with titles; enable saved content deliberately.

Choose **Import → Browse files / Browse folder** for independent copies. Choose **Linked sources → Link folder** on a supported local desktop workspace if you want to edit original Markdown with explicit Save. These are different ownership models: [Import and export](transfers.md), [Linked sources](linked-sources.md).

## Find your way

Opening a file shows a preview; opening a note uses a workspace pane. **Return to notes** restores the current note workspace. Open Notes keeps sessions that are not currently visible. [Panes and history](navigation.md) explains these distinctions.

Help is bundled read-only application content. Reading or searching it never creates notes, changes collections or exports Help with your workspace. The Help home offers areas, tasks and local search; Back returns to earlier Help locations. Select text to copy instructions, or use Copy article for Markdown.

## Before you rely on a platform

Check [Platform support](platforms.md). This Help Center is development work after desktop 0.26.0; already installed 0.26.0 apps do not contain it. It does not add Android Help or change Android functionality.
