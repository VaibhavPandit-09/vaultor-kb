# Linked sources and external Markdown

## Link instead of import

On supported Windows / Apple Silicon Mac **This computer** workspaces, open Linked sources and choose **Link folder**. Use the native picker to authorize the source. Linking retains external ownership and folder hierarchy; importing makes independent managed copies. Browser, remote/independent server connections and Android cannot acquire this local editing authority.

The source tree loads bounded directory pages. Open admitted Markdown files from the tree; linked references can join collections, tags and Pinned without moving or copying their originals. Portable workspace archives contain references only, never linked source bytes or filesystem permissions.

## Edit and Save

Linked Markdown uses explicit **Save**. Visual editing preserves supported original syntax and protects unsupported source blocks. Single-click supported Markdown hyperlinks (or focused Enter) to navigate through authorized source resolution. Reference-style preview links work; editable reference syntax remains protected and wikilinks remain literal. No automatic heading scrolling is promised.

An unsafe or ambiguous edit can be refused while retaining the draft. Large documents are bounded to 1 MiB with additional block/node limits; large code/table regions can be protected. This is not a promise of lossless arbitrary Markdown editing or uniformly fast very large documents.

## Changes, conflicts and recovery

Vaultor checks source identity, bytes and supported metadata before writing. Other-app changes, missing/replaced paths and uncertain receipts need review. Do not repeatedly retry a Save whose outcome is uncertain. Compare offers reviewed combination only for safely disjoint changes; overlap requires the offered keep/export/reload/reapply choices. No automatic merge or recovery write replaces your original.

Private recovery retains base, validated and visual versions within bounds. Export any versions you need before confirmed removal of private recovery copies. Source removal does not mean the file was deleted. Locate source folder after portable import requires fresh native consent; an archive never conveys access.

## Filesystem restrictions

Supported local Windows NTFS and Mac APFS configurations are checked natively. Unsafe aliases, unsupported volumes/metadata and special files are refused. Symlink/junction escape is not authorized. macOS uses the unsandboxed personal Apple Silicon distribution; Intel Mac and Linux are not supported releases. Concurrent external writers still require conflict care. [Platforms](platforms.md), [Recovery](recovery.md).
