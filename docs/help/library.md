# Library and organization

## Resources and browsing

Resources are managed notes, original files or references to linked Markdown. Notes open in panes; files use supported previews. Unknown types are identified without guessing how to open them. Library, Recent, collection contents and Pinned show bounded pages of up to 100 items, with pagination when needed.

Use the Type filter, title search, tags and Search options to narrow a page. All selected tags must match. Recent orders by last opening; other browsing sorts include updated time and title. Saved-content search uses relevance instead. Filters and page changes clear bulk selection.

**Pinned** contains resources and collection shortcuts. Pinning does not move or duplicate content. **Recent** reflects opening history, not unsaved changes. Sidebar options lets you customize quick access; the current desktop quick groups show six Pinned and six Recent entries, with full destinations available separately.

## Collections

Choose New collection beside New note or use Collections. Collections can be nested. Their menus offer relevant creation, rename, move, pin, import and management actions. Names must be unique among siblings after normalization.

A resource can belong to several collections. **Add to collection** adds membership. **Remove from [collection]** removes only that membership. Moving a collection changes the hierarchy; it does not move source files. Deleting a collection reviews its subtree: the default keeps original resources. The optional Trash mode affects only exclusively contained active managed originals. Read the review before approving. Linked originals remain externally owned.

## Tags

Use **Manage tags** in a resource's Actions menu to apply or remove tags. The Tags destination supports browsing and management. Tag names are case-insensitive and have persistent colors. Several tags can be applied to one resource; hierarchy and tag merging are unsupported. Sidebar quick tags are bounded suggestions, not the entire tag inventory.

## Actions and context menus

Use the ellipsis, right-click, or ContextMenu / Shift+F10 on a focused supported item. Applicable actions include opening, organization, pinning, copying, export/download and Trash. A selected-row menu targets the selection; a row outside that selection targets itself. Editable text retains text context behavior. Menus support arrows, Enter and Escape.

See [Selection, clipboard and dragging](interactions.md), [Search](search.md) and [Trash](recovery.md).
