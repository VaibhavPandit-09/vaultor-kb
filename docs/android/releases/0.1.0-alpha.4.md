# Vaultor Android 0.1.0-alpha.4 — images and native file handling

Android-only personal prerelease. Package `com.vaultor.app`, versionCode4, original APK signer retained. Requires Android16/API36 or later; targets Android17/API37. Existing desktop/Mac0.7.1 hosts and protocol3 remain compatible and unchanged. A4 only; organization mutations (A5), complete themes/touch/motion polish, discovery and in-app updates (A6) remain later work.

## What changed

- Add images/files through Photos, Files, Camera, clipboard or existing-image search. `/image` opens Photos. Android Share stages files/text for an explicit source note rather than inserting into the wrong note.
- Original PNG/JPEG/WebP/GIF bytes stay as File resources. Tap an image for proportional width, alignment, caption, alt text, replacement, preview, copy/save original and removal of that placement. Undo remains a document transaction.
- Uploads keep encrypted local bytes and stable import UUIDs through failures. Source-note/host binding and mapped insertion anchors prevent navigation from redirecting an upload. Pending-input feedback and explicit retries remain available after interruption.
- Authenticated lazy thumbnails and temporary image/PDF/text previews retain the mounted editor/journey. Other file formats offer Save/Open with. Native clipboard/share/SAF use private temporary content URIs, never saved paths or credentials.
- Pairing reveals its verification controls even with several remembered hosts. Media errors retain the current tools/input values and offer retry.

## Install or update

Download **Vaultor-Android-0.1.0-alpha.4.apk** from this release on the phone, open it and accept Android's installation/update prompt. Allow installation from that browser/file manager if Android asks. Install over the existing Vaultor app; **do not uninstall or clear its data**. Approvals, sessions and recovery records remain local. Only the APK is needed; checksum/manifest assets are optional verification material. Android's in-app updater is still A6.

Enable Sharing on the desktop host and use the existing remembered connection, or enter its private HTTPS address and match/approve its comparison code. A4 requires no host reinstall. No Play Store account, payment or direct agent phone access.

## Checks and limits

TypeScript,40focused Jest tests, editor structured-content/refusal/media insertion/undo/duplicate-placement tests and scoped lint passed. Signed release/application-test compilation and package/version/API/original-signer/arm64+x86_64/16KiB checks passed. Android16 and17 emulator storage/media/UI checks cover encrypted staging/restoration, lost import acknowledgment retry, original byte equality, bounds, clipboard insertion/tools/save/preview, picker cancellation and mixed Share staging. A staged input survived actual force-stop/relaunch. Final tagged-source APK evidence is recorded in [the tracker](../../plans/android-plan.md) after publication.

Disposable host verification confirmed standard saved attributes/backlinks and successful PDF/Word/Markdown-assets operations. PDF contains image objects; Word and Markdown packages contain PNGs and captions; Markdown retains alt text. Word currently does not emit image alt text as an accessibility description. No visual export-layout or physical-screen certification is claimed.

Inline supported images:20MiB/40MP; files:64MiB; pending input:8items/80MiB. Preview images are static first-frame, bounded to2048pixels per edge; animated originals are preserved. PDF preview:20MiB, one page at a time; text preview:first100KB. Temporary clipboard/share URIs can expire after cache cleanup/host switching. No full offline browsing/sync or audio/video player. See [MEDIA.md](../MEDIA.md) for authoritative cache/security bounds and interrupted-input behavior.

Samsung Galaxy S24 Ultra, Samsung Keyboard clipboard, One UI8.5/9 camera/share/SAF, real Wi-Fi/Mac transfers, TalkBack and OEM battery/process behavior remain **user-only, unverified**. Stock Android emulator success is not Samsung certification. To try A4: paste/select a screenshot, resize/caption/save, reopen it, preview and Save original; try Share into Vaultor and explicitly choose its destination note. Report issues without providing credentials or personal note bodies.
