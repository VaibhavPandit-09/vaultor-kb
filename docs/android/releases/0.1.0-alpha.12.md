## Changes and review boundary

- Shared Smooth/Snappy motion tokens and conservative OS reduced-motion handling; Reading appearance is the first measured bottom-sheet demonstration.
- Central native semantic haptics: action-oriented standard feedback, capability-checked rich envelopes/primitives, coherent fallback, native foreground/system/app preference checks, bounded duplicate suppression and lifecycle cancellation.
- Device-local Touch feedback System/Off and explicit Preview selection/Preview completion. Ordinary reading/navigation/theme/background work stays silent; no feedback on every tap.
- Coordinated control-origin theme reveal across activity/modal, retaining mounted controls/reader and using bounded32MiB memory-only snapshots with interruption/timeout/allocation fallback. Main/modal system-bar icons, modal safe areas and keyboard resizing are coordinated.

[Interaction foundations](../INTERACTION-FOUNDATIONS.md) owns implementation details; [approved A0–A5 phases](../ANDROID.md) owns the review gates. A1–A5 remain unstarted. Original editing, Review capture/outbox/sync, imports, exports and broader settings are not introduced.

## Install and review

Install the release APK over the existing app; **do not uninstall or clear app data**. Open navigation → Appearance & reading. Compare Light/Dark/OLED and Preview selection/Preview completion with app System/Off and Android touch feedback enabled/disabled. Check keyboard, rotation and Back. The JSON/checksum files are verification metadata; manual installation needs only the APK.

**Physical acceptance is pending and user-owned:** high-quality actuator feel, haptic/keyframe synchronization, Samsung/OneUI, physical OLED, important touch/motion perception, TalkBack and real system-bar/provider behavior are not certified by these emulators. Agents never access/pair the phone. Installed native reader-content snapshot fidelity and broader reader/control continuity remain an explicit A2 validation gate; this slice's native visual demonstration uses the existing appearance surface over hostless/disposable Home. Source-level reader DOM identity tests passed, not an invented full native reading certification.

Stop at A0 for review before A1.
