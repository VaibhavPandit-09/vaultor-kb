## Reading and media

Reading options offers Outline, Find within note, Reading appearance and Journey. Flat device-only controls provide OS/Light/Dark/OLED, four accents, text size/spacing/measure and Snappy/Smooth. OS follows the system; OLED is black. Find works across formatting without replacing text nodes. Read-only tasks, tables and code retain meaning and local horizontal overflow. Links remain selectable; external HTTP(S) opening requires confirmation. Source/revision-checked reading positions restore distinct journey visits and cold starts; leaving for Library supersedes pending linked navigation.

Images and PDFs open a full-screen temporary native viewer with Fit, Actual size, zoom/pan/pinch and original-file Save/Share/Open with/Copy where supported. Images have a bounded source-note gallery; PDFs have page navigation. Pages/zoom/pan persist per source-scoped resource without reopening previews on restart. Originals are unchanged. Password-protected/oversized/unsupported content gets actionable feedback. See [reader](https://github.com/VaibhavPandit-09/vaultor-kb/blob/2d7b406f0de71713fefd4c323f5f37a78f34e3fb/docs/android/READER.md) and [media](https://github.com/VaibhavPandit-09/vaultor-kb/blob/2d7b406f0de71713fefd4c323f5f37a78f34e3fb/docs/android/MEDIA.md) for exact bounds.

Legacy recovery remains intact and read-only: reconnect never replays pending document writes. Complete offline workspace downloads/reviews/import/export remain later sprints. No editable note engine is bundled.
