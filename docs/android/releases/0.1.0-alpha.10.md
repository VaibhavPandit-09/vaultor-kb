# Android 0.1.0-alpha.10 — beautiful reading (R2)

Package com.vaultor.app; versionCode14; minimumAPI36/targetAPI37; protocol3; original APK signer unchanged. Android-only prerelease; no host/desktop/schema/archive update. R3–R10 remain unstarted.

## Reading and media

Reading options offers Outline, Find within note, Reading appearance and Journey. Flat device-only controls provide OS/Light/Dark/OLED, four accents, text size/spacing/measure and Snappy/Smooth. OS follows the system; OLED is black. Find works across formatting without replacing text nodes. Read-only tasks, tables and code retain meaning and local horizontal overflow. Links remain selectable; external HTTP(S) opening requires confirmation. Source/revision-checked reading positions restore distinct journey visits and cold starts; leaving for Library supersedes pending linked navigation.

Images and PDFs open a full-screen temporary native viewer with Fit, Actual size, zoom/pan/pinch and original-file Save/Share/Open with/Copy where supported. Images have a bounded source-note gallery; PDFs have page navigation. Pages/zoom/pan persist per source-scoped resource without reopening previews on restart. Originals are unchanged. Password-protected/oversized/unsupported content gets actionable feedback. See [reader](../READER.md) and [media](../MEDIA.md) for exact bounds.

Legacy recovery remains intact and read-only: reconnect never replays pending document writes. Complete offline workspace downloads/reviews/import/export remain later sprints. No editable note engine is bundled.

TypeScript/native original-key release compilation,22 focused Jest cases, reader DOM/runtime checks and scoped lint0errors/32warnings passed. Build-release now gates TypeScript before signing. An Android17 viewport-expansion bug affecting pinch was corrected with a fixed internal scroll viewport and disabled competing browser zoom, with a media-runtime regression check. A real native label hit-target issue was fixed: noninteractive label children now leave taps with the owning Pressable. Failed harness attempts are not counted as passes.

API37 passed all six installed cases, including real text selection/native Copy, pinch and gallery swipe, normal approved pairing, cold position restore, OS/reduced motion and retained recovery. OLED/Light/landscape frames were inspected. The same fixed-viewport candidate passed all six cases on API36 too, with the retained130% font profile. Exact tagged-source/publication gates remain pending. Screenshots/emulator checks cannot certify physical OLED, Samsung OneUI8.5–9, real Wi-Fi/Mac, TalkBack speech or OEM lifecycle. Test geometry/selector differences were corrected without bypassing native gestures. Large-workspace stress/OOM certification remains R10.

## Artifact and installation

Release publication pending. The immutable source tag, APK checksum/size and verified GitHub asset status will be recorded after final gates; a development candidate is not the completed release.
