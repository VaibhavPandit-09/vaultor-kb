# Vaultor Android 0.1.0-alpha.6.1 — Effortless writing

Android-only personal prerelease. Package com.vaultor.app/versionCode7, original APK signer retained. Requires Android16/API36 or later; targets Android17/API37. Existing desktop/Mac0.7.1 hosts and protocol3 remain compatible; no host update is required. This implements A6 only; A7 organization, A8 settings/discovery/updater and A9 integration remain unstarted.

## What changed

- Edits are protected locally before debounced automatic host saves. Status distinguishes On this phone, Saving and Saved to host. Retry preserves drafts; conditional revision checks retain both versions on conflict.
- Durable save receipts reconcile uncertain acknowledgments before retrying. Typing during a save stays protected and is saved afterward; no editor reload or selection replacement is used.
- Edit has one compact Insert/Format/Undo/Redo accessory. Existing notes remain read-first. Short tools retain the current document/selection; ordinary Save is removed.
- Image tools put width, alignment and caption first; More contains alt, replacement, preview, copy, original download and placement removal. Originals and mapped upload identities remain unchanged.
- New note on Home/browsing captures the collection destination, persists one UUID before dispatch and retries that same creation after failure/restart. A confirmed note opens directly for editing with the keyboard.

## Install or update

Download **Vaultor-Android-0.1.0-alpha.6.1.apk** from this release, open it and accept Android's update prompt. Allow installation from that browser/file manager if asked. Install **over the existing Vaultor app; do not uninstall or clear data**. Only the APK is required; JSON/checksum files are optional verification metadata. The in-app updater follows in A8. Remembered Mac/Windows connections continue to work with Sharing enabled.
