## What changed

Android now reads saved notes through a restricted structured DOM renderer, without an editable Tiptap engine. Compact navigation/title/More replaces editing tools. Home resume/Recent/Pinned, mixed Library/search/collections, approved workspace selection, note journeys and temporary original-file previews remain. Note editing, creation, organization/lifecycle writes and image placement/upload tools are removed from normal flows and refused by the native boundary. Normal change events reconcile without reopening the stream; browsing and selected reading DOM survive unrelated refreshes.

Legacy drafts (including uncertain sent payloads), creation/lifecycle identities and encrypted pending upload bytes survive upgrade. **Legacy recovery** inventories them separately and exports a private ZIP with readable notes, original JSON/identities and original retained files through Android's Save destination. No recovery is automatically replayed or acknowledged and no original is overwritten. Export progress/failure/retry and duplicate prevention are local. Keep the exported ZIP private; it is not a workspace archive/import input.

## Install and use

Download **Vaultor-Android-0.1.0-alpha.9.1.apk** from this release and install over the existing app. **Do not uninstall or clear data.** JSON/checksum files are verification metadata, not app imports. Existing approved protocol3 hosts remain compatible; no host upgrade is required for R1.

Open navigation → Legacy recovery to export earlier pending work. Originals are read-only on Android. Use desktop/browser for editing. Current cache remains last-opened saved content only (12 notes/8MiB), not a downloaded workspace. Beautiful reading/media refinements come in R2; complete companions/reviews/import/export capabilities follow their separate gates.
