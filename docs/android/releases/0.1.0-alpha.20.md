## Changes

- `NavigationFolio.tsx`: three equal Home/Library/Review slots, consistent line icons,
  concise label hierarchy and traveling selection mark. Sources and browsing More
  no longer reserve bottom space. Interruptible strip clipping transforms into
  focused reader controls; actual window insets drive compact/rail adaptation.
- `SourceContext.tsx`, `WorkspaceScreen.tsx`: compact heading source identity and
  material offline/connection status, full accessible label, existing checked Sources
  workflow. Reader retains contextual source access. Global Review has no active
  source control; Sources remains in Vaultor options. Existing management, download,
  recovery, connection and utilities remain available.
- `BrowseScreen.tsx`, `browsePresentation.ts`: compact Library hierarchy, count and
  Resume on one scrolling row; useful collection names rather than repeated Note /
  collection counts. Current-scope membership is omitted without mutating records;
  fallback counts are grammatical. File formats remain meaningful. Offline content
  coverage and draft exclusions remain in search options and relevant active states.
  Virtualization, query/filter/page/scroll ownership remain unchanged.
- `NavigationSurface.tsx`, `ReviewDestination.tsx`: remove duplicate destination
  heading/source text now owned by the shell orientation row.
- Focused metadata/window/state tests and Android interaction cases; Android-only
  package/lock/Gradle version increment. CODEBASE, Android current docs and index
  updated. AGENTS and philosophies unchanged.

No production Kotlin, security/admission/effect, domain/storage/sync, source/generation,
journal identity, resource/API/backend, desktop or framework/dependency change.
The native test class changes only runtime assertions and acceptance coverage.
The existing semantic haptic architecture and restrained usage policy are preserved.
