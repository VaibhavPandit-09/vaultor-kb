# Vaultor Android 0.1.0-alpha.7.1 — A7 organization and lifecycle

Android-only prerelease candidate. Desktop/Mac remains 0.7.1, API protocol3; no host update or schema migration is required. A8/A9 remain separate, unstarted sprints.

## Changes

- One contextual Actions sheet across mixed browsing, note More and temporary file previews. Collections/resources can be renamed; pins, tags and collection memberships use captured workspace/epoch targeting. Tag names travel in JSON, preserving canonical API-path protection.
- Collections can be created with a durable UUID. Add resource searches bounded title metadata and commits immediately, with Added/retry feedback. Suggested and explicit note creation reuse A6's atomic import/collection destination and durable creation identity.
- Incoming/outgoing saved References use pages of30. Occurrence opening verifies source revision/path/target before selecting the saved link/image without editing its JSON. Draft or changed occurrences open the source with an explanation.
- Trash title browsing, Restore with the same ID, saved-usage review, explicit permanent deletion and durable cleanup Retry. Unknown outcomes retain the exact UUID/revision/body; successful items acknowledge only their matching journal and leave bulk selection. Long-press reveals contextual selection. Collection deletion/membership removal/image placement removal do not delete originals.
- Foreign Trash retains protected content and unavailable visits; restored notes offer explicit saved/recovered choices. The former draft stays in Recovery.

## Install and limitations

After publication, download only Vaultor-Android-0.1.0-alpha.7.1.apk from its release and install over the existing app. Do not uninstall or clear app data; its original signer/package preserves approvals, sessions, drafts and pending media. The manifest/checksum are verification metadata, not files to import into the app. A8 owns in-app update discovery/install handoff.

Samsung S24 Ultra, One UI8.5/9, Samsung Keyboard, TalkBack, physical OLED, actual Wi-Fi/Mac races and OEM lifecycle remain user-only/unverified. The agent uses explicit Windows emulator serials and disposable hosts, never the phone. No offline synchronization, Android-hosted server or tablet/DeX parity is claimed.
