# Vaultor Android 0.1.0-alpha.7.2 — Organization and lifecycle

Android-only prerelease candidate, versionCode10. Desktop/Mac0.7.1 and host protocol3 remain unchanged; no host update, schema migration or desktop rebuild is required. A8 settings/discovery/updater and A9 integration remain unstarted.

## Changes

- Shared contextual Actions from mixed rows, note More and temporary file previews: conditional rename, pins, tags, collections, saved References and resource lifecycle. Long-press starts contextual selection; collection rows are excluded from resource bulk operations.
- UUID-backed collection creation and immediate Add resource with Added/local retry feedback. Suggested/explicit note creation reuses A6's atomic collection destination. Name conflicts preserve editable input only after the host confirms the failed UUID is absent; uncertain/busy/existing-UUID outcomes retain their original request.
- Incoming Used in / outgoing Links to use bounded pages of30. Opening an occurrence checks saved revision/path/target without changing document JSON or undo. Pending drafts and changed paths open the source with an explanation.
- Trash title browsing, saved-usage review, same-ID Restore, explicit permanent deletion and durable cleanup Retry. Partial results retain unfinished selections and operation identities; another device's committed cleanup intent remains authoritative. Collection membership, placement removal and original deletion are separate actions.
- Foreign Trash retains protected drafts and unavailable visits. Restored conflicts offer explicit saved/recovered choices while retaining the former draft independently. Files remain temporary previews; images remain File resources with original bytes.

## Installation

After publication, download only Vaultor-Android-0.1.0-alpha.7.2.apk from its GitHub release and install over the existing app. Do not uninstall or clear app data: the original signer/package preserves approvals, sessions, drafts and pending inputs. JSON/checksum assets are verification metadata, not files to import. A8 owns in-app update discovery and Android's installation-consent handoff.

## Limits

Samsung S24 Ultra/One UI8.5–9, Samsung Keyboard, TalkBack, physical OLED, actual Mac/Wi-Fi races and OEM lifecycle remain user-owned/unverified. Agents use explicit Windows emulator serials/disposable hosts and never the phone. No offline synchronization, Android hosting or tablet/DeX parity is claimed. ORGANIZATION.md owns exact retry/deletion/reference behavior. Definitively failed Restore/purge items offer Refresh Trash and review again; uncertain requests retain their identity. Storage cannot guarantee survival of every abrupt interruption.
