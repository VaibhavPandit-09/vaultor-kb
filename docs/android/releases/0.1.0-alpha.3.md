# Vaultor Android 0.1.0-alpha.3 — browsing, search and journeys

Android-only prerelease, versionCode **3**, package **com.vaultor.app**. Requires Android16+ and a protocol3 host (Windows/Mac0.7.1). Original APK signer, desktop/server/archive contracts and manual Save remain unchanged.

## What changed

- Native Library, Recent, Pinned and Collections replace the first-30-notes screen. Mixed metadata lists use server pages of 100, content-sized rows, one Type filter and local Retry; Pinned collection shortcuts open their collection.
- Title search remains the default. **Saved content** opts into saved note/indexed file text with plain snippets and coverage information. **Scope** chooses a collection without losing the query. Open drafts are excluded.
- Inline note links extend a single active-note journey. Back, Forward and the searchable Journey sheet revisit retained steps and reading positions; direct browsing opens start a new trail. Cycles are distinct visits, branches replace forward steps, and the trail is bounded to 200 visits.
- Library keeps the editor/draft mounted. Query, type, scope, sort, page and reading/browsing positions survive returning and restarting. Obsolete replies are discarded; different workspace generations cannot reuse rows or layout.
- More groups Hosts and Recovery in a compact header. Touch targets, link focus/activation and the editor's surrounding navigation are improved. Inline-link Enter activation cannot insert a newline.
- File links open temporary **information** sheets and leave the note/journey intact. Actual image/file viewing and insertion arrive in A4; resource mutations in A5; complete themes/touch/motion and Android updates in A6.

## Install/update

Download **Vaultor-Android-0.1.0-alpha.3.apk** from the published Android release and install over the existing app. **Do not uninstall or clear data.** The checksum/JSON assets are verification metadata, not installation inputs. No desktop/Mac host update or repeat pairing is needed. Save explicitly; protected drafts remain local until acknowledged by the host.
