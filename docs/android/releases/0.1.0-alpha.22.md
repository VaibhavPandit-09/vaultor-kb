## Review completion contract

Flag for review freezes evidence and opens a protected unfinished composer. R5
requires a nonblank comment (1–5000 characters); empty comments remain invalid.
Typing protects a Draft. Keep draft, scrim and Back do not publish unfinished text.
One Create Review waits for protection and durably queues the same UUID/body.
Review created confirms local durability. Delivery then shows Queued, Syncing,
Synced or Needs attention; desktop Open/Resolved/Dismissed remains separate.
Existing protected drafts are not automatically completed. A failed protection or
queue write retains prior evidence and cannot publish partially protected text.

Queue commit triggers foreground delivery immediately, including a coalesced
follow-up if another batch already took its snapshot. Resume/verified reconnection
and30s active-app opportunities retry safely. Recoverable admission failures are
rechecked at60s without weakening admission. Unknown outcomes resend the exact
UUID/frozen body. Terminal generation/UUID/evidence conflicts require attention.
Sync now remains optional. Permission may require explicit Android grant. Android
suspension/force-stop has no immediate-delivery guarantee; foreground catch-up is
supported. Source switching never retargets or activates the captured source.

or Review-row target. Noninteractive scrims are absent from the spoken action tree.
Draft counters do not announce every keystroke. Created receipt uses a polite live
region; Review rows include a bounded distinguishing comment/evidence summary.
Receipt refresh uses native events/resume instead of2s encrypted-journal polling.

left native WebView pixels over Library. The retained layer now has a non-collapsible
native owner with opacity/z-order ownership and stable measured geometry. Final
runtime results below determine readiness; the initial failed run is not a pass.

Lifecycle, retained source/Review identity, keyboard/Back, reduced motion, font
scaling, system insets and upgrade checks use the installed Android runtime.
Spoken TalkBack/focus usability, Samsung Keyboard, One UI9 edge gestures/OLED and
OEM lifecycle/battery behavior remain pending user acceptance. No physical-device

## One S24 Ultra acceptance script

1. Install this APK over alpha.21 without clearing data. Confirm previous sources,
   protected drafts/queued Reviews, reader position and Aa preferences remain.
2. In a disposable approved desktop workspace open a downloaded note. Select a
   passage and Flag for review. Confirm source/evidence; blank Create Review is
   disabled. Type an unfinished comment, Keep draft, reopen it from device-wide
   Review and verify exact evidence/comment. Do not complete that draft yet.
3. Create a separate capture with a complete comment and Samsung Keyboard visible.
   Tap Create Review once. Confirm Review created, then Synced automatically and
   exactly one matching desktop Review. No second save or Sync now. Original note
   body and captured evidence must remain unchanged.
4. Disconnect the host/Wi-Fi. Create another complete Review, confirm Queued, close
   and force-stop Vaultor. Reopen offline: draft, queued evidence and reader position
   remain. Reconnect and foreground Vaultor; confirm automatic delivery once only.
5. Resolve/dismiss the delivered Review on desktop. Foreground Android (allow up to
   one30s active catch-up interval) and confirm matching desktop status. Repeated
   foreground/reconnect must not duplicate it. Sync now is an optional comparison.
6. Switch between two sources with different browsing state. Review remains device
   wide; original source provenance is clear. Revoking approval or replacing a
   generation must show attention/lock, retain evidence and never redirect delivery.
   Do not reset personal workspaces just to exercise this destructive fixture case.
7. Check Home/Library/Review, source management, Aa, note open/Back, Find and media.
   Confirm list query/scroll, reader identity and position survive the round trip.
8. Check Light/Dark/OLED, larger text, portrait/landscape, gesture/system Back and
   reduced motion. With Samsung Keyboard open, first Back hides it; subsequent Back
   keeps the unfinished draft. Create action/evidence must remain reachable.
9. With TalkBack, traverse heading, evidence, required comment, Create Review and
   Keep draft. Confirm understandable order, quiet typing counter, clear completion
   announcement and useful return focus. Assess real touch/motion/haptics yourself;
   most ordinary navigation remains silent. Report defects; no agent approval is
   implied by automated checks.

R6 remains an acceptance candidate until the user completes this gate. No official
release, R7 or merge is authorized.
