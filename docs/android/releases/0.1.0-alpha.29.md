# Vaultor Android 0.1.0-alpha.29

Install this update over **0.1.0-alpha.28**. In Vaultor open **Settings → App updates**, check for the update, verify it and confirm the Android installation prompt. You can also download `Vaultor-Android-0.1.0-alpha.29.apk` here and choose **Verify a downloaded APK** in Vaultor. Keep the existing app installed and keep its data.

The upgrade preserves your paired source and selected workspace, saved offline readings, Review drafts and pending Reviews, collected originals and reader preferences. Continue using your existing Windows 0.27.0 host. A compatible Vaultor Next engineering host needs its own pairing and workspace grant. Use its pairing QR or verify the host's CA fingerprint and compare the matching code. **Collected imports** can submit a workspace ZIP to that host for the owner's review. Pending work stays tied to its source.

This is an Android-only prerelease. It requires Android 16 (API 36) or later. Windows Next install-over is awaiting an installer and verified workspace migration. Physical Samsung, camera and real Wi-Fi acceptance remain separate.
