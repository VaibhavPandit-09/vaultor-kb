## Changes

- Sources overlays the retained reader, brings approved workspace selection and verified downloads together, and discloses remembered connections/manual pairing separately. Host and workspace stay distinct; full native source scope remains the routing identity.
- Compact orientation puts availability before long workspace names. Connected, downloaded/offline, cached, unavailable and approval-required states stay distinct. Home resumes the actual note, with its saved reading position.
- Library secondary orientation/filter/coverage/resume controls share the single measured list instead of consuming permanent rows. Search/filter summary remain reachable; rows are denser without reducing action targets.
- Drawer disclosure state survives dismissal; a bounded edge surface uses shared native-driver motion and safe areas at all widths. Shared utility sheets coordinate native modal ownership, bottom entry, IME, bars and heading focus. Sources and legacy recovery inspection preserve the existing WebView.
- Explicit verified source activation uses standard semantic H2 after modal release; explicit refusal uses H4 with the local error. Background changes and ordinary navigation remain silent. Haptics Off/reduced motion retain visible behavior. No new rich effect or raw vibrator call.

No host/API/protocol/database/resource/archive/desktop change; original notes and files remain immutable. Review capture, durable queue, idempotent upload and desktop status remain unimplemented.

## Review/install

Install only the APK over the existing app; **do not uninstall or clear data**. Check Home→Library→reader→Sources→Back; switch workspaces; explicitly read a download; resume from Home; reopen collapsed drawer sections; try filters, keyboard and landscape. Check long workspace names still leave offline mode visible. Compare system/app touch feedback enabled and Off during explicit source activation/refusal.

**User-owned physical acceptance remains pending:** haptic feel/keyframe agreement, real touch/system gestures, Samsung/OneUI, OLED, cutouts/system bars, TalkBack/trigger restoration, large text and OEM lifecycle/performance. Agents never access/pair the phone. Exact reading-edge restoration through future continuous chrome transformations, predictive progress/cancellation and media refinement remain A2 gates. A1 uses natural single-list orientation reclamation; it does not claim continuous title migration or tablet/DeX parity.
