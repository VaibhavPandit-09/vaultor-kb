## Review/install

Install only the APK over the existing app; **do not uninstall or clear data**. Check Home→Library→reader→Sources→Back; switch workspaces; explicitly read a download; resume from Home; reopen collapsed drawer sections; try filters, keyboard and landscape. Check long workspace names still leave offline mode visible. Compare system/app touch feedback enabled and Off during explicit source activation/refusal.

**User-owned physical acceptance remains pending:** haptic feel/keyframe agreement, real touch/system gestures, Samsung/OneUI, OLED, cutouts/system bars, TalkBack/trigger restoration, large text and OEM lifecycle/performance. Agents never access/pair the phone. Exact reading-edge restoration through future continuous chrome transformations, predictive progress/cancellation and media refinement remain A2 gates. A1 uses natural single-list orientation reclamation; it does not claim continuous title migration or tablet/DeX parity.
