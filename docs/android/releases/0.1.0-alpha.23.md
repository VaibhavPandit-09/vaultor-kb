## What is included

- Source-bound offline reading with verified retained downloads, local search, original images/PDFs and restored reading position.
- Protected Review drafts and immutable evidence independent of cache/download retention. Flag opens a draft; Keep draft/Back never publishes. One Create Review durably queues a nonblank comment with the exact original UUID/body/source.
- Automatic foreground Review delivery and reconnect/resume recovery, exact retries after uncertain outcomes, duplicate avoidance, and separate desktop Open/Resolved/Dismissed status reconciliation. Durable sending claims and prior receipts survive restart/revocation; conflicts retain evidence for attention.
- Reader-first Home/Library/Review navigation, quick source selection separate from source management, retained reader identity, reversible resource-origin motion and contextual reader Aa controls.
- Accessible settings paths, themes/reading size/spacing, reduced motion, IME/Back/insets and bounded adaptive layouts. React Native remains the product UI; thin Kotlin owns platform capabilities and semantic haptics.
- Existing legacy recovery records, original-resource read-only enforcement and signing/upgrade continuity remain intact. Android does not edit original notes or write desktop Review status.

The publicly available Windows0.14.0 production frontend/backend/desktop trees match the merged release baseline; no newer desktop package is required. [Mac0.13.0](https://github.com/VaibhavPandit-09/vaultor-kb/releases/tag/v0.13.0) lacks Review capability; it is not a Review-delivery host. Do not downgrade archive4 host data to it.

## Known limitations and remaining acceptance

This milestone remains an alpha/prerelease. Samsung S24 Ultra subjective motion/haptics, spoken TalkBack, Samsung keyboard/One UI/OLED, actual Wi-Fi and OEM lifecycle/battery, sustained physical-device performance and integrated Mac native verification are not certified. These are documented nonblocking follow-ups under the user's milestone-release authorization. No phone access occurred.

Delivery is best effort while active/resumed; suspended or force-stopped delivery is not guaranteed. Permissions/reapproval may require explicit user action. Generation/immutable UUID conflicts require investigation and never retarget evidence. Retained reading content relies on Android sandbox/device encryption; Review journals are separately encrypted. No independently writable mobile workspace, queued imports, full/partial workspace export, R7 implementation or Android1.0 stability claim is introduced.
