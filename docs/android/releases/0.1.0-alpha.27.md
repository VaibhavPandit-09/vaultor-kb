## Limits and acceptance

Offline partial exports faithfully cover available verified checkpoints; hidden R7 import provenance and all-host Review inventory are unavailable offline and explicitly disclosed. Markdown rendering is approximate with exact JSON sidecars. No offline PDF/Word/full ZIP. Host transfer cache retains its existing manual-cleanup behavior/256 companion claim admission bound; no perpetual cache reclamation guarantee. Update check is bounded to100 official releases; manual APK fallback remains available. An interrupted APK download restarts safely rather than promising HTTP range resume. Force-stopped/background execution and external recipient saves are not guaranteed.

No physical S24, TalkBack, OEM feel/battery, real-LAN discovery or native Mac certification. R10 owns integrated Small/Atlas performance/lifecycle/accessibility/scale and final cross-device/release readiness; R8/R9 implementation does not authorize it. Public publication/master integration still requires user approval.
