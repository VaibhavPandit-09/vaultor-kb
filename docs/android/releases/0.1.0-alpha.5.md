# Vaultor Android 0.1.0-alpha.5 — Android-first navigation

Android-only personal prerelease. Package com.vaultor.app, versionCode5, original APK signer retained. Requires Android16/API36 or later; targets Android17/API37. Existing desktop/Mac0.7.1 hosts and protocol3 remain compatible and unchanged. This is A5 only; four sprints A6–A9 remain.

## What changed

- A workspace drawer is reachable while reading or browsing. It holds Home, Library, Collections, Search, mixed collapsible Pinned/Recent shortcuts, connections and Recovery. Wide windows dock it on the same left edge; phone windows use an overlay.
- Home offers search and bounded recent/pinned previews. Library keeps one search field plus contextual Filters instead of permanent destination/type strips. Query, scope and scroll context remain retained.
- Existing notes open for reading, with Edit and More. The same editor/document/undo remains live when entering Edit or temporarily browsing. Journey is available through More rather than a permanent strip. Images in reading mode open temporary previews.
- Edit opens the Android keyboard; layout reserves its space. Back dismisses transient UI/keyboard before leaving Edit, then traverses the note journey and browsing origin. Connection diagnostics are on demand, while draft-protection errors remain actionable.
- Shared surfaces follow OS Light/Dark, with true-black dark canvases and unchanged image pixels. Explicit theme/accent preferences follow in A8.

## Install or update

Download **Vaultor-Android-0.1.0-alpha.5.apk** from this release on your phone, open it and accept Android's update prompt. Allow installation from that browser/file manager if asked. Install **over the existing Vaultor app; do not uninstall or clear data**. Only the APK is required; the checksum and manifest are optional verification material. No host reinstall is required. Android's in-app updater remains A8.

Approvals, scoped sessions and protected recovery stay local. Keep using the remembered Mac/Windows host with Sharing enabled. No payment, Play Store account or agent access to your phone is required.

## Transitional editing and remaining work

**Save is still explicit and appears only in Edit.** Done returns to reading; it does not promise a host save. Unsaved edits remain protected locally and visible. A6 must prove safe autosave before removing Save and consolidating insertion/formatting into a compact writing accessory. Existing image tools remain A4's transitional UI. Creation/organization follows A6/A7; settings/discovery/updates A8; expressive motion/final integration A9. Drawer collapse state lasts for the current opening, not a persisted preference.

## Checks and limits

TypeScript,45focused Jest tests, editor schema/refusal/read-only/theme/media/undo checks and scoped ESLint passed (zero errors/38 warnings). Original-key release/application-test compilation and package/version/API/arm64+x86_64/16KiB alignment checks passed. Android16 and17 each passed one actual pairing/read/Edit/keyboard/typing/undo/conditional-save/Back/drawer/filter/inline-link interaction test and nine native storage/media/UI regression cases. Installation over the retained application preserved approval/session data.

The targeted visual session covered reading, keyboard editing, image preview, mixed Small shortcuts, empty search, narrow900x2100 with130% font, Light and true-black dark. Wide docking was corrected to retain the left edge. Final tagged-source/artifact results are recorded in the tracker after completion; source publication alone is not a delivered APK.

Early failed harness runs assumed pairing controls were visible despite many remembered hosts and assumed reconnect always opened Home; the test now scrolls and accepts restored Library. Header accessibility uses the declared header role rather than the former TextView class. A real keyboard-opening failure and edge-to-edge overlap were corrected, not waived. Failed or interrupted runs are not counted as passes.

Samsung Galaxy S24 Ultra, Samsung Keyboard, One UI8.5/9, TalkBack, physical OLED, actual Wi-Fi/Mac behavior and OEM battery/process lifecycle remain user-only/unverified. No full offline browsing/sync, Android server, tablet/DeX parity. No FPS/full-heap certification.
