## Scope and implementation

`NavigationFolio.tsx` replaces the old drawer and shell topbar with one adaptive
Home/Library/Review + distinct Sources context surface. Destination slots change
width around a traveling accent edge. The destination strip retracts through a
clip at its normal intrinsic text size; Back expands and the context control
takes the released space in reading. Large text uses two browsing rows; genuinely
wide windows use a rail. No duplicated browsing bar remains in focused reading.
Disclosure is owned by central Back handling. Sources opts into measured,
native-driven reversible MotionSheet exit with bounded window cleanup.

`WorkspaceScreen.tsx` coordinates those states and retains the workspace/reader
under Review. `NavigationSurface.tsx` retains Home and removes WorkspaceDrawer;
`BrowseScreen.tsx` supplies its own destination heading after topbar removal.
`navigationPresentation.ts` owns window thresholds, bounded memory-only utility
browse history and full-provenance Review grouping. `ReviewDestination.tsx` reads
the device-wide journal. `ReviewCapture.tsx` can reopen an existing journal ID
without beginning/duplicating a record or activating a source; the composer and
save/haptic behavior otherwise remain unchanged. ContextSheet adds opt-in exit
props only; other callers keep their existing immediate-dismiss ownership.

Focused Jest and `NavigationExperienceTest.kt` cover new failure-prone behavior.
`CaptureExperienceTest.kt` changes only its navigation entry helper to the new shell.
Package/lock/Gradle advance the Android version only. CODEBASE, Android entry/source/
reader docs, the trace feedback note and documentation index describe the new
prototype. AGENTS and both philosophy documents are unchanged.

No production Kotlin effect/security/storage/companion/transport code, domain schema,
R5/R6 provenance, journal identity, API/protocol, original resource, sync or desktop
change. No new product library/framework, Compose or minimum-platform change.
