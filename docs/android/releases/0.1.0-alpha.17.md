## Product delta

Alpha.16 already had a hybrid native effect engine. This pass makes the semantic boundary explicit and restrictive, keeps React Native as the primary UI/motion framework, removes Find/accent and custom-anchor usage, and reserves one named REVIEW_CAPTURED pattern. Kotlin VaultorHaptics.kt and VaultorPresentation.kt changed; no new native module/Compose screen/audio/network path. Clear completion uses the existing alpha.16 authored CLICK.65→60ms→CLICK1.0 composition; no claimed stronger/new waveform. Other profiles/fallback/settings remain capability-aware and manufacturer-independent.

Native-driven measured utility entries use300/220ms instead of360/280; contextual capture retains360/280 with same native window/source/evidence. Saved band independently owns completion; comment contraction/expansion remains interruptible. Reader compression, Find edge entry, original-pixel Fit, source orientation and coordinated theme reveal are retained after actual audit; no speculative blanket animation change.

Removed: Find H1, accent H1, rich product anchor. Remaining: standard H2 at evidence/source/Fit endpoints, reserved H3 REVIEW_CAPTURED after durable local commit/visible receipt/hidden IME, H4 explicit visible rejection, manual labelled previews. H1/H5 remain independently tunable; H5 has no product caller. Routine navigation/open/scroll/type/results/theme/background/reopen saved are H0.
