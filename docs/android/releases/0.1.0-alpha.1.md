# Vaultor Android 0.1.0-alpha.1 — A1 prototype

Android-only prerelease: one signed APK, package `com.vaultor.app`, versionCode 1, Android 16+ (API36), target Android17/API37, arm64 phones and x86_64 emulators. Desktop Windows/Mac 0.7.1 remains unchanged. Host protocol 3 is required. No fees or Play Store account.

Secure manual private IPv4 HTTPS pairing with matching-code approval, remembered native credentials, first 30 notes, restricted locally bundled Tiptap, manual conditional Save and one encrypted protected draft are available. Current structured content survives round-trip; unknown document attributes/nodes block unsafe editing. Managed images remain descriptive placeholders with their resource references intact.

This is an editor/trust prototype for a disposable workspace. Full browsing, multiple hosts, autosave, complete conflict/recovery choices, images/previews, organization, themes and in-app updates follow A2–A6. Revision conflict retains the journal and blocks editing. No offline synchronization or phone-hosted server.

Release compilation, TypeScript, 3 bridge checks, full-schema/unknown-content/Save-lock tests and 3 Android native tests per emulator passed. Installed Android16/17 release checks covered pairing, restart without repeat approval, software keyboard/undo/redo, protected draft force-stop recovery, conditional Save, failed Save/Retry, unsupported JSON, rotation and renderer-failure safety. Android17 permission denial/retry and 16 KiB-page launch passed. Frame checks used Windows emulators; no Samsung phone access, actual Wi-Fi/Mac-host or One UI certification is claimed. Tooling advisories and later gates are documented in the guide.

Download **Vaultor-Android-0.1.0-alpha.1.apk** and install it on the phone. Other assets are verification metadata; no JSON import is needed. Enable Sharing on the desktop host, enter its private IPv4 HTTPS address, allow local-network permission if requested, match and approve the code on the host, then confirm approval in the app. Save manually. After typing, wait for protected-draft status before testing force-stop. Never uninstall/clear app data as an update or recovery step.

The original Android APK certificate SHA-256 is `af1123bd0be38ee48ce61b4f40f3667c4fe740910b64005d3d21dacd83de2567`. Published APK bytes are accompanied by SHA256SUMS.txt/android-release.json. Android update signing is independent of desktop. Future APKs retain this identity and increase versionCode.

See [Android setup, installation, test evidence and S24 checklist](https://github.com/VaibhavPandit-09/vaultor-kb/blob/master/docs/android/ANDROID.md). A2 requires separate authorization; this release does not claim final mobile parity.
