## Source and local durability

Capture is separate evidence, never an original note/file edit. Reader selection exposes Flag for review without replacing native Copy. Reading options offers Add review item; preview controls offers whole-file Add review item separately from Review PDF page N. The page action uses one-based PDF page only after the current page render acknowledgment. Pending/error page requests cannot become page evidence. Same resource titles/UUIDs in different workspaces do not substitute source identity.

The composer freezes host/workspace/generation/resource/base revision, title/type, display host/workspace, full quote, context and locator. Selection is bound to reader load/source/resource/revision before its transient range disappears. A single-block DOM path is converted from /0/1 to R5 0.1 and validated against saved JSON text; multi-block selection uses whole-resource evidence without claiming a block. Quote limit4000 is refused, never silently shortened. Context is an explicit bounded surrounding excerpt≤4000; excerpt boundaries preserve UTF-16 pairs. Comment1–5000 nonblank characters at queue commit; base revision≤100; locator paths≤64segments/300characters; PDF pages1–100000. Native validation repeats bounds. Files are resource/page evidence; no PDF rectangles or extracted selection precision.

VaultorReviews owns a separate AES-GCM/Android Keystore encrypted AtomicFile vaultor-reviews.bin under noBackupFilesDir. It reuses the established native key identity, not the legacy state file. One native serialized owner plus a journal lock protects read/modify/write. Format1,256retained entries and8MiB plaintext bound; admission fails rather than evicts. Corruption/unsupported versions fail closed and retain bytes. No journal data enters ordinary archives, recovery ZIPs, download budgets, renderer storage or host requests. Approval removal/download eviction cannot remove captures. Names/addresses/timestamps are display provenance; credential and authenticated author are absent.

Native begin admits the selected host/epoch/workspace, and rechecks downloaded-source availability/lock. A draft receives a native UUID before editing; native protection is atomic. Comment changes serialize with version checks. The UI distinguishes Protecting from Protected; dismiss awaits outstanding protection. On failure, an explicit choice keeps editing or closes with the last protected draft; confirmed discard can still execute after failed protection, using the retained version guard. A kill before protection is acknowledged cannot promise the latest keystroke; the last protected draft remains recoverable from Captures on this phone. This is not a device backup.

Create Review waits for protection and atomically marks the same UUID/body queued. Repeated queue commit returns the same frozen row. Queued evidence is read-only in A3; draft discard requires explicit confirmation. A4 adds native dispatch and status to the global Review destination; original-write routes remain absent. Draft recovery and queued inspection retain the same journal. A4 preserves exact frozen creation input (including baseRevision, which GET receipts omit), and admit the captured generation/grant before dispatch. Never route through the currently focused workspace.

## Completion versus protection

R5 requires a nonblank comment, so Flag for review opens an unfinished protected draft. Typing protects without publishing. The prominent Create Review header action waits for pending protection, then atomically queues the same UUID/frozen payload and requests automatic delivery. Keep draft, Back and scrim preserve unfinished work; no second save or manual sync is required after completion. Existing drafts remain drafts. Review created confirms local durability, separately from Queued/Syncing/Synced/Needs attention delivery.

## Interaction specification

The same reader/viewer remains mounted beneath one contextual window throughout preparation, protected composer and receipt. Native onShow plus measured ready geometry gate its full-height entrance. After protected evidence is visible, its source-labelled region settles24dp over shared anchor200/180ms; H2 occurs at that endpoint. Durable queue commit changes semantic state immediately, then the same comment contracts140 to72dp while a measured saved-status band expands; Queue success releases the software IME. H3 targets the visible saved band after its geometry settles and the keyboard is hidden, not the first state frame. Disclosure can interrupt comment geometry without stopping or clipping the independent receipt. Reopening queued evidence is silent. Expand saved comment animates back to240dp. Receipt height measures text for larger font scales. A single bounded ScrollView (65%window/600dp, shrinking for IME) retains input/evidence; native multiline input scrolls within it. No separate preparatory modal, duplicate entrance or scrim handoff remains. Comment disables landscape fullscreen IME extraction. ContextSheet consumes visible-IME Back and its bounded250ms hide handoff; a subsequent Back closes normally. A very fast second Back within that interval is consumed. Keep draft/scrim preserve drafts; queued inspection uses Done. Failed protection still offers close with last protected draft; confirmed discard keeps version guards. Captures remain bound independently of active source. Local storage errors never imply a host connection is required.
