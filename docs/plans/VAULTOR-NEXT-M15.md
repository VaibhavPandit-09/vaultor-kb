## Implementation and interaction states

- Settings keeps the original floating surface, category motion, compact rows, keyboard choices and opacity. Contextual Help retains Settings and returns focus on Escape. Original Appearance/Workspace/Layout & previews/Keyboard are reconciled with supported controls; General and Application describe Next startup/storage. One/two-pane capacity, fill/reuse opening, 0–1000ms autosave and focus mode persist in root-bound workspace SQLite settings. Appearance/sidebar/preview/bindings remain installation preferences. Reducing capacity crosses the existing Save/protect barrier before retaining displaced sessions. Reset scopes are explicit; linked files still require explicit Save.
- Original WorkspacePaneLayout now owns pane entry, focus, compression, interruption and reading anchors. Its optional host weights retain Next's divider without changing original defaults. Slots, sessions and the shared document owner stay separate. Open Notes has real arrangement handles and menu alternatives; duplicate keyboard cycling targets session identity, never resource identity.
- Collection pins live in the same SQLite organization domain with collection foreign keys, separate from resource IDs. Both entity kinds share the paged/counted Pinned browser and Quick Access. Ordering remains alphabetic, matching the original contract; drag arrangement applies to sessions, not an invented manual pin-order model. Workspace archives retain collection pins and behavior; old archives remain accepted, while older Next readers can refuse added metadata.
- Note titles use original display/edit states over existing managed journaling, with explicit finish/cancel. Header export and resource actions remain resource-scoped. The selection toolbar clamps to the pane, follows scroll, preserves text focus and dismisses below nested popovers. Original code/table/slash/link controls remain; code copy injects Rust clipboard services and language menus get keyboard/Escape ownership. File previews reuse the original PreviewShell over retained editors.
- Library tag filtering queries the complete paged taxonomy. Original type controls include supported filename categories with accurate SQLite totals/cursor identity. Category labels describe original filenames, not new decoding engines. Linked indexing, new media engines and advanced table/CSV operations remain excluded.
- Companion drag discovery is temporary; cancellation restores Chosen/Auto context. Resource drops onto Pinned preserve ownership; collection drops retain existing membership semantics. Sidebar width is bounded and supports pointer/keyboard controls. No document bodies enter receipts and reading metadata retains the M14 debounce/bounds.
