# M14 everyday interaction restoration

Reviewed 2026-11-12. Continues `codex/vaultor-next-m1` from `37b8999`. **M14 is partially complete.** This is engineering evidence, not user acceptance or application-wide UI parity. No master merge, installer, tag or publication.

## Implementation and reference

- Original `PaneNavigation`, `JourneyBar`, `JourneyViewport` and `OpenNotes` now drive Next sessions, visible assignments, per-session journeys, reading scroll/caret, ordering and close-one/other/all. Rust loading, managed flush and linked draft protection are injected. Only assigned pane editors mount;the compact peer stays assigned/mounted during compression. Explicit shared views can resume by session ID rather than accidentally selecting the first view of a resource.
- Direct opens retain independent sessions; resource/relative links extend their source journey. Journey boundary shortcuts stay inside the session. Workspace history is available in the application menu while editing, without duplicate arrow sets. Default Ctrl+Alt+Left/Right navigates journeys, Alt+Left/Right focuses panes and Ctrl+Alt+PageUp/PageDown cycles Open Notes. Live hints reflect customized bindings.
- Original Quick Access configuration/disclosure/type primitives retain Pinned/Recent visibility, collapse and type. Six-summary Rust queries stop while hidden/collapsed/inactive; pins are alphabetic and Recents chronological. Chosen companion context wins over navigation; per-category scroll is debounced into workspace receipts. Primary Collections/Tags/Sources remain full browsers.
- The original resource type control supports currently implemented Notes/Files filters, true totals and cursor identity. Unsupported kinds refuse in Rust. Existing page selection and resource actions remain; the note header now opens those actions, shows pin state and uses original `SaveIndicator`. The original pure `ResourceLinkChip` is shared without old HTTP metadata ownership: ordinary click follows, Ctrl-click opens beside.
- Settings adds actual density, fixed/floating sidebar, Quick Access configuration, motion preview and confirmed appearance/sidebar/keyboard/all-profile resets. The shared floating frame, opaque text and60–100% CSS surface opacity remain. No preference is presented as native wallpaper-visible alpha.
- Single-pane reading keeps the original896px bound. The main-workspace container, rather than window width, owns compact two-pane presentation; inactive compact peers retain their editors. Shared journey motion replaces the obsolete additional Next workspace fade/slide.

Persisted journeys are metadata only: at most24 sessions/96 visits, bounded UTF-8 serialization within the unchanged32KiB native receipt limit. Runtime journeys retain the original200-visit limit. Position changes debounce700ms; they do not serialize documents or rerender the shell for every scroll pixel. Undo remains memory-only. Third-pane support is not a dependency of the two-pane journey adapter and remains missing.
